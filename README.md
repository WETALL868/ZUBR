# Премиум Ворота — сайт компании по установке ворот

Многостраничный сайт на Next.js (App Router) + TypeScript + Tailwind CSS для компании, которая
устанавливает, изготавливает и обслуживает откатные, секционные и распашные ворота, а также
занимается автоматикой и ремонтом.

## Стек

- Next.js 16 (App Router, React 19, TypeScript, строгий режим)
- Tailwind CSS 4 (дизайн-токены заданы в `src/app/globals.css`)
- Zod — серверная валидация форм
- Nodemailer — отправка заявок на email
- Telegram Bot API — отправка заявок в Telegram

## 1. Установка зависимостей

```bash
npm install
```

## 2. Запуск локально

```bash
npm run dev
```

Сайт будет доступен на [http://localhost:3000](http://localhost:3000).

## 3. Production-сборка

```bash
npm run build
npm run start
```

Перед сборкой полезно прогнать проверки:

```bash
npx tsc --noEmit   # проверка типов
npm run lint       # ESLint
```

## 4. Где менять название компании и ключевые условия

Все данные компании находятся в **одном файле**: `src/config/site.ts`.

Там задаются: название, город и регион (`[ГОРОД И РЕГИОН]` — плейсхолдер, замените на реальный,
например «Москва и Московская область»), телефон, email, Telegram, WhatsApp, адрес, часы работы,
юридические реквизиты, ссылки на соцсети, координаты офиса, гарантийный срок, сроки изготовления,
минимальная цена и текст главного предложения.

Ничего из этого не размазано по другим файлам — компоненты и страницы всегда импортируют значения
из `siteConfig`.

## 5. Где менять телефон и адрес

Там же, в `src/config/site.ts`: поля `phone`, `phoneHref`, `address`, `officeCoordinates`,
`requisites.legalAddress`.

## 6. Где добавлять фотографии

Все изображения лежат в `public/images/`. Сейчас там временные SVG-иллюстрации — см.
`IMAGE_REQUIREMENTS.md`, где расписано, какой файл на какой реальной фотографии нужно заменить,
с рекомендуемой ориентацией и разрешением. Достаточно положить файл с тем же именем (или обновить
путь в соответствующем файле `src/data/*.ts`).

Если хотите перегенерировать плейсхолдеры (например, после правки палитры):

```bash
node scripts/generate-images.mjs
```

## 7. Как добавлять проекты в портфолио

Портфолио хранится в `src/data/portfolio.ts` — массив `portfolioItems`. Каждый объект содержит тип
ворот, район (используйте нейтральные плейсхолдеры, не настоящие адреса клиентов без согласия),
размер, установленную автоматику, список работ и пути к фотографиям. Поддерживается пара
«до/после» через поле `beforeAfter`. Компонент `PortfolioGallery` (`src/components/portfolio/`)
сам подхватит новый элемент, фильтры и полноэкранную галерею.

## 8. Как настроить отправку заявок

Все формы сайта отправляются на `POST /api/lead` (`src/app/api/lead/route.ts`). Обработчик:

- валидирует данные через Zod (`src/lib/validation.ts`);
- проверяет honeypot-поле и минимальное время заполнения формы (антиспам);
- ограничивает частоту запросов с одного IP (`src/lib/rate-limit.ts`);
- пытается отправить заявку на email и в Telegram (`src/lib/notify.ts`);
- если ни один канал не настроен, заявка попадает в серверный лог — это нормально для
  локальной разработки, но перед публикацией сайта настройте хотя бы один канал.

## 9. Как подключить Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите `TELEGRAM_BOT_TOKEN`.
2. Узнайте `TELEGRAM_CHAT_ID` (личный чат, группа или канал, куда бот должен писать).
3. Добавьте оба значения в `.env.local` (см. `.env.example`).

## 10. Как подключить электронную почту

Заполните в `.env.local`: `LEADS_EMAIL` (куда приходят заявки), `SMTP_HOST`, `SMTP_PORT`,
`SMTP_USER`, `SMTP_PASSWORD`. Подходит любой SMTP-провайдер (Yandex, Mail.ru, корпоративная почта
и т.д.).

## 11. Как подключить карту

Компонент `src/components/contact/Map.tsx` рендерит iframe на основе `siteConfig.map`:

- `siteConfig.map.provider` — `"yandex"` или `"2gis"`;
- `siteConfig.map.yandexEmbedUrl` / `siteConfig.map.twoGisEmbedUrl` — ссылки на виджет карты с
  нужными координатами. Получить embed-ссылку можно в конструкторе виджетов Яндекс.Карт или 2ГИС,
  указав `siteConfig.officeCoordinates`.

## 12. Как подключить аналитику

В `.env.local` укажите `NEXT_PUBLIC_YANDEX_METRIKA_ID` и/или `NEXT_PUBLIC_GA_ID`. Компонент
`src/components/layout/Analytics.tsx` подключит нужные скрипты автоматически; если переменные не
заданы, аналитика просто не подключается и ошибок не возникает.

Цели (`src/lib/analytics.ts`, функция `trackGoal`) уже расставлены в коде:

- `lead_submit` — успешная отправка любой формы;
- `quiz_complete` — прохождение квиза-калькулятора;
- `phone_click` — клик по номеру телефона;
- `messenger_click` — клик по WhatsApp/Telegram;
- `calculator_open` — открытие калькулятора.

## 13. Как заменить демонстрационные отзывы

Отзывы находятся в `src/data/testimonials.ts`. Массив явно помечен как демонстрационный
(поле `isDemo: true` в типе `Testimonial`) — перед публикацией замените тексты, имена, районы и
фотографии на реальные отзывы клиентов (желательно с их согласия и ссылкой на источник).

## 14. Как развернуть сайт на сервере

Сайт — обычное Next.js-приложение, подходят любые варианты хостинга Next.js:

- **Vercel** — самый простой вариант: подключить репозиторий, задать переменные окружения из
  `.env.example` в настройках проекта, деплой произойдёт автоматически.
- **Node-сервер** — собрать (`npm run build`) и запустить (`npm run start`) за reverse proxy
  (Nginx) на порту, который слушает Next.js (по умолчанию 3000).
- **Docker** — обернуть `npm run build` + `npm run start` в стандартный Node-образ.

Во всех случаях перед деплоем нужно задать переменные окружения из `.env.example` в настройках
хостинга (SMTP/Telegram/аналитика).

## Структура проекта

```
src/
  app/                     # страницы (App Router), API route, sitemap/robots/manifest, иконки
  components/
    ui/                    # базовые UI-компоненты (кнопки, поля форм, карточки, модалки)
    layout/                # шапка, подвал, мобильная панель, cookie-баннер, аналитика
    lead/                  # квиз-калькулятор, формы заявок, модальные окна расчёта/замера
    home/                  # секции главной страницы
    portfolio/             # галерея портфолио и лайтбокс
    shared/                # переиспользуемые блоки (FAQ, хлебные крошки, форма расчёта и т.д.)
    seo/                   # JSON-LD, хлебные крошки
    contact/               # карта
  config/site.ts           # ЕДИНЫЙ конфиг компании
  data/                    # услуги, типы ворот, преимущества, этапы, FAQ, портфолио, отзывы и т.д.
  lib/                     # валидация, отправка писем/Telegram, rate-limit, SEO-хелперы, аналитика
  hooks/                   # общий хук отправки форм
  types/                   # общие типы данных
public/images/              # изображения (см. IMAGE_REQUIREMENTS.md)
scripts/generate-images.mjs # генератор временных SVG-иллюстраций
```

## Важно перед публикацией

1. Заменить все плейсхолдеры в `src/config/site.ts` (город/регион, телефон, email, соцсети и т.д.,
   если что-то из уже заполненного нужно изменить).
2. Заменить временные SVG-иллюстрации в `public/images/` на реальные фотографии — см.
   `IMAGE_REQUIREMENTS.md`.
3. Заменить демонстрационные отзывы в `src/data/testimonials.ts` на реальные.
4. Заполнить портфолио реальными объектами в `src/data/portfolio.ts`.
5. Настроить хотя бы один канал приёма заявок (email или Telegram) — см. пункты 9–10 выше.
6. При необходимости подключить аналитику (пункт 12).
