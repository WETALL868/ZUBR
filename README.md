# LANCOR — лендинг «Настройка локальной сети и интернета для офиса»

Статический лендинг под трафик из Яндекс.Директ. Без сборки, без зависимостей,
без внешних запросов — распаковать и залить на любой хостинг.

## Структура

```
index.html              главная страница
privacy-policy.html     политика обработки персональных данных (152-ФЗ)
cookie-policy.html      политика использования файлов Cookie
terms.html              пользовательское соглашение + реквизиты владельца сайта
robots.txt
sitemap.xml
assets/
  css/style.css       вся стилистика и дизайн-система
  js/main.js          меню, scroll-reveal, sticky CTA, форма, cookie-баннер
  img/favicon.svg
  img/apple-touch-icon.png
  img/og-cover.png    1200×630 для соцсетей и мессенджеров
```

Все четыре HTML-страницы используют один и тот же `assets/css/style.css` и
`assets/js/main.js` и полностью повторяют шапку, мобильное меню, футер и
цветовую схему — так что дизайн выглядит как единый сайт, а не набор
самостоятельных страниц.

## Что заменить перед публикацией

| Что | Где |
|---|---|
| Телефон `+7 (495) 000-00-00` и e-mail `info@lancor.ru` в шапке/футере/форме | `index.html`, `privacy-policy.html`, `cookie-policy.html`, `terms.html` |
| Домен `lancor.ru` | `canonical`, `og:url`, `og:image`, `robots.txt`, `sitemap.xml` во всех страницах |
| Плейсхолдеры `[указать номер телефона]` / `[указать адрес электронной почты]` / `[указать доменное имя сайта]` / `[дата вступления в силу]` — подсвечены жёлтым, намеренно не выдуманы | `privacy-policy.html`, `cookie-policy.html`, `terms.html` |
| Название `LANCOR` | все страницы |
| Регион обслуживания | секция контактов на главной |

**Важно:** плейсхолдеры вида `[указать ...]` в юридических документах — это
не декоративный текст, а обязательные поля. Реквизиты ИП (ФИО, адрес, ИНН,
ОГРНИП, банковские реквизиты) уже подставлены настоящие и менять их не нужно;
не хватает только контактного телефона/e-mail оператора, доменного имени
сайта и даты, с которой документы вступают в силу — их нельзя было
придумывать самостоятельно.

## Юридические страницы и согласие пользователя

- **`privacy-policy.html`** — оператор персональных данных, цели и основания
  обработки, перечень данных, сроки хранения, права пользователя, порядок
  отзыва согласия, обработка при обращении по телефону/e-mail. Банковские
  реквизиты сюда намеренно не включены.
- **`terms.html`** — предмет соглашения, права/обязанности сторон,
  интеллектуальная собственность, ограничения использования, ответственность,
  и раздел 12 «Реквизиты Владельца сайта» с полными банковскими реквизитами.
- **`cookie-policy.html`** — технические/функциональные/аналитические cookie,
  использование Яндекс Метрики, инструкция по отключению cookie в популярных
  браузерах, работа cookie-баннера.

Ссылки на все три документа проставлены в четырёх местах, как и требовалось:
футер (все страницы), блок рядом с формой заявки, чекбокс согласия под формой,
и cookie-баннер («Подробнее» → `cookie-policy.html`).

Чекбокс согласия (`#f-consent`, атрибут `required`) блокирует отправку формы
нативной HTML5-валидацией — без отметки `form.checkValidity()` возвращает
`false` и `main.js` не даёт форме уйти в отправку.

### Cookie-баннер

Показывается один раз, пока в `localStorage` нет ключа `lancor_cookie_consent`.
«Принять» и «Отклонить» одинаково скрывают баннер навсегда (до очистки данных
браузера) и записывают `accepted`/`declined`. Пока в проекте не подключён
реальный счётчик Яндекс.Метрики — если/когда его добавите, загружайте его
скрипт только при `localStorage.getItem('lancor_cookie_consent') === 'accepted'`.

## Подключение формы заявок

В `assets/js/main.js` в начале файла:

```js
var LEAD_ENDPOINT = null; // -> "/api/lead"
```

Пока значение `null`, форма валидируется и показывает успех локально, никуда не
отправляя данные. Укажите свой обработчик — он должен принимать `POST` с JSON:

```json
{ "name": "...", "phone": "...", "seats": "...", "task": "...", "intent": "...", "page": "..." }
```

Поле `intent` содержит текст кнопки, с которой пришёл пользователь
(«Получить консультацию» / «Заказать настройку») — удобно для аналитики Директа.

Защита от спама: скрытое honeypot-поле `contact_reference`. Оно намеренно **не**
называется `company`/`organization` — такие имена заполняет автозаполнение
браузера, из-за чего реальные заявки молча отбрасывались бы.

### Цель в Яндекс.Метрике

После успешной отправки вызывается `reachGoal('lead_form_submit')`, если на
странице подключена Метрика и задан `window.__ymCounterId`:

```html
<script>window.__ymCounterId = 12345678;</script>
```

## HTTP-заголовки безопасности

Страница не делает внешних запросов, поэтому политику можно задать жёстко.
Настраивается на стороне хостинга/веб-сервера (в `<meta>` вынесено намеренно не
было, чтобы не ломать статику при изменении разметки).

Nginx:

```nginx
add_header Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; form-action 'self'; base-uri 'self'; frame-ancestors 'none'" always;
add_header X-Content-Type-Options "nosniff" always;
add_header Referrer-Policy "strict-origin-when-cross-origin" always;
add_header X-Frame-Options "DENY" always;
add_header Permissions-Policy "geolocation=(), microphone=(), camera=()" always;
```

`'unsafe-inline'` для script нужен из-за инлайнового `class="js"`-переключателя в
`<head>` и JSON-LD; при подключении Метрики добавьте её домены в `script-src`,
`img-src` и `connect-src`.

Apache (`.htaccess`) — те же значения через `Header always set`.

## Производительность

Проверено в Chromium: LCP ≈ 0.16 с, CLS = 0, горизонтального скролла нет на
ширинах 320–1920 px. Страница полностью читается с отключённым JavaScript —
анимации появления включаются только при наличии класса `js` на `<html>`.
