# Сайт СНП «Новая Искань»

Официальный сайт садоводческого некоммерческого партнёрства.

## Устройство проекта

Сайт — это готовые статические страницы плюс небольшая серверная часть
на PHP. Сборщика страниц нет: HTML правится напрямую, как и было
в переданном архиве. Node.js нужен только для разработки и проверок —
на хостинге он не требуется.

```
index.html, about/, news/, documents/, …   страницы сайта
_next/static/chunks/*.css                  основной файл стилей (с хешем в имени)
assets/site.css                            слой мобильных исправлений
assets/site.js                             меню, фильтры, cookie, форма
assets/admin.css                           стили административного раздела
assets/img/                                готовые изображения (npm run images)
assets/source/                             исходники изображений
api/appeals/                               приём обращений
admin/                                     закрытый раздел правления
_private/submissions/                      сохранённые обращения (создаётся сервером)
docs/                                      документация и данные каталога
tools/                                     инструменты разработки
tests/                                     тесты
```

Основной файл стилей `_next/static/chunks/*.css` намеренно не
изменяется: у него хеш в имени, и правка содержимого без смены имени
оставила бы посетителям с прежним кешем старую версию. Все правки
лежат в `assets/site.css`, который подключается следом.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | поднимает сайт на http://127.0.0.1:8080 |
| `npm run check` | линтер, проверка типов, тесты и сборка архивов |
| `npm test` | тесты |
| `npm run lint` | линтер JS, PHP и HTML |
| `npm run typecheck` | проверка типов |
| `npm run build` | собирает архивы в `dist/` |
| `npm run documents` | пересобирает страницу «Документы» |
| `npm run images` | пересобирает изображения из `assets/source/` |
| `npm run audit:responsive` | проверка вёрстки на 10 ширинах |
| `npm run screenshots` | скриншоты на 375, 768 и 1440 px |
| `npm run photo:oka -- …` | установка фотографии Оки в футер |

Для локального запуска нужны PHP 8 и Node.js 20+.

## Настройка

Логин и пароль администратора хранятся в `config.php`. В репозитории
его нет — есть только образец `config.example.php`. Перед первым
запуском скопируйте его:

```bash
cp config.example.php config.php
```

## Как публикуются документы

Состав каталога описан в `docs/documents-catalog.json`. Файлы кладутся
в `documents/files/` под именами из поля `file`. После этого
`npm run documents` пересобирает страницу: у карточек с уже
загруженными файлами появляется кнопка «Скачать», у остальных
остаётся статус без ссылки — чтобы на сайте не было переходов,
ведущих на ошибку 404.
