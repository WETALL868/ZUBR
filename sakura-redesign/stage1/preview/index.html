Рекомендация: C «Мой принтер» с табличным видом из B

Главная причина покупки в магазине картриджей: найти точно подходящую модель. Направление C делает совместимость основой интерфейса: принтер сохраняется один раз, каталог и поиск сужаются, карточка сразу отвечает «подходит или нет». Это снижает ошибки и возвраты и одинаково работает на телефоне.

  • Из B взять переключатель «Таблица» в каталоге и наличие по складам: удобно при 2000–3000 SKU и для покупателей, которые знают код.
  • Из A взять предметные изображения только для категорий и раскрытого меню, без крупных фото в каждом блоке.
  • Логотипы производителей одним рядом с равным визуальным весом, без плиток.

Что нужно для C

Справочник «производитель → серия → модель принтера» и связи с SKU уже заложены в модели данных (CartridgeCompatibility). Для выбранной CMS потребуется модуль или доработка сохранения принтера и фильтрации; оценка после согласования платформы.

После выбора направления: полный магазин для 1440, 1920, 1024, 390 и 360 px, компоненты и переменные Figma, кликабельный прототип и предпросмотр с демо-данными.
