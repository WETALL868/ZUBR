# SAKURA: редизайн магазина (Claude)

Отдельный проект Sakura в каталоге `sakura-redesign` репозитория WETALL868/ZUBR. Магазин инструментов ZUBR/ГРАНЬ, его тема, база и сервер не затрагиваются. Работа ведётся в ветке сессии без слияния в main и без публичной публикации.

Обратная ссылка на исходный чат Codex: `codex://threads/01a188df-b6fc-7ae1-a439-af6f4944bc25`. Автоматической синхронизации между Claude и Codex нет; результаты переносятся вручную. Подробности передачи: [HANDOFF.md](HANDOFF.md).

## Этап 1: три направления

| | Направление | Шрифты | Суть |
|---|---|---|---|
| A | Витрина | Literata + Onest | Сдержанная предметная фотография, разрежённая сетка, тёплые нейтральные поверхности |
| B | Прайс | IBM Plex Sans + Plex Mono | Строгая коммерческая сетка, таблицы, дерево каталога, наличие по складам |
| C | Мой принтер | Manrope | Сохранённый принтер, подбор в три шага, отметка «Подходит» в каталоге и карточке |

Рекомендация: C с переключателем «Таблица» и наличием по складам из B. Обоснование: [stage1/index](stage1/preview/index.html) и `stage1/exports/00-overview.png`.

В каждом направлении: главная 1440, каталог лазерных картриджей HP 1440, карточка CE285A 1440, главная 390, карточка 390 (первый экран и прокрутка с фиксированной панелью покупки).

- Figma: https://www.figma.com/design/6aMHGbcuXzqn4Ppb0gl1i0?node-id=42-242 (страница «SAKURA / Claude / Варианты 2026-10-30»). Существующая страница концепта 05 не изменена.
- Экспорты: `stage1/exports/*.png`, сравнение главных `00-compare-home.jpg`.
- Предпросмотр в браузере: открыть `stage1/preview/index.html` локально (ссылки на экраны внутри).
- Карта экранов и требований: `stage1/REQUIREMENTS-MAP.md`, `stage1/requirements-map.json`.
- Изображения, промпты и источники логотипов: `stage1/IMAGES.md`.
- Незавершённое: `stage1/NOT-DONE.md`. Предложения по применимости: `stage1/PROPOSED-CHANGES.md`.

Данные демонстрационные: цены CE285A и других картриджей взяты с текущего sakurarussia.ru 30.10.2026, остатки, склады и сроки условные. CMS, платежи и доставка не подключались.

## Сборка

Нужен Node 18+ и Playwright с Chromium (для экспорта PNG).

```bash
node src/build.mjs
```

```bash
node src/shoot.mjs stage1/preview stage1/exports
```

```bash
node src/figma-docs.mjs /tmp/sakura-figma
```

`build.mjs` собирает HTML со ссылками на `assets/`; `figma-docs.mjs` собирает по одному документу на направление со встроенными шрифтами и изображениями для импорта в Figma через `html_to_figma`.

Шрифты (OFL): Literata, Onest, IBM Plex Sans, IBM Plex Mono, Manrope из пакетов @fontsource, файлы в `assets/fonts`.
