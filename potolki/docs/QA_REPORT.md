### Ключевые сценарии калькулятора

Проверены на детерминированном прайсе, где суммы можно пересчитать вручную:

- прямоугольная комната 4 × 5 → площадь 20 м², периметр 18 пог. м;
- несколько комнат с общим итогом;
- дополнительные углы сверх четырёх;
- теневой профиль (цена по периметру);
- световые линии и блоки питания (округление вверх: 250 Вт → 3 блока);
- высота выше стандартной — коэффициент применён **только к работам**,
  материал полотна не подорожал;
- выезд за бесплатную зону (20 платных км из 50);
- скидка с исключением выезда из базы;
- минимальная сумма заказа отдельной строкой;
- отрицательные, текстовые и абсурдные значения — отклонены с указанием поля;
- сумма, присланная браузером, игнорируется: сервер считает заново.

## 2. Проверка в браузере — 112 проверок на 7 ширинах, проблем 0

16 страниц × ширины 360, 390, 430, 768, 1024, 1440, 1920 px.

Для каждой комбинации проверено:

- ровно один `H1`;
- заполненные `title` и `description`, наличие `canonical`, `lang="ru"`;
- **отсутствие горизонтальной прокрутки** (`scrollWidth == clientWidth`);
- у всех изображений есть `alt`;
- у всех полей ввода есть связанный `label` или `aria-label`;
- отсутствие ошибок в консоли браузера;
- наличие микроразметки JSON-LD.

Исправлено в ходе проверки:

1. Горизонтальная прокрутка 25 px на калькуляторе при 360–390 px — кнопки
   «Дублировать» и «Удалить» не переносились. Добавлен перенос и `min-width: 0`
   у элементов сетки.
2. Ошибка в консоли: калькулятор запрашивал расчёт до ввода размеров и получал
   422. Теперь запрос уходит только при заданных размерах, а до этого
   показывается подсказка.
3. Кнопка «Рассчитать стоимость» в шапке ломалась на две строки; на узких
   экранах её заменяет нижняя панель действий.
4. Атрибут `hidden` перебивался классами с `display: flex` — добавлено правило
   `[hidden] { display: none !important; }`.

## 7. Известные ограничения текущей сборки

1. **Фотографий нет.** На первом экране — схематичный план потолка, а не
   стоковый интерьер. Список нужных съёмок — в `IMAGE_BRIEF.md`.
2. **Прайс предварительный.** 55 позиций требуют подтверждения владельцем
   (`DATA_REQUIRED.md`, раздел 3).
3. **Реквизиты не заполнены**, поэтому юридические страницы не индексируются.
4. **Районы Москвы (119 страниц) и станции метро — черновики.** Это осознанное
   решение: публиковать их можно только с собственным содержанием, иначе это
   дорвеи. Проверка `tests/run.php geo` не позволит опубликовать пустую страницу.
5. **Почта в режиме `log`** — письма не отправляются, пока не настроен SMTP.
