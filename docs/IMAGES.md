# Изображения проекта

Все изображения хранятся внутри проекта. Внешние ссылки на картинки
не используются: сайт должен открываться, даже если сторонний сервис
недоступен.

- Исходники: `assets/source/`
- Готовые варианты: `assets/img/` (собираются командой `npm run images`)

## Фон первого экрана и шапок внутренних страниц

| | |
|---|---|
| Исходник | `assets/source/hero-road-production.png`, 1672×941 |
| Происхождение | входил в переданный архив сайта |
| Где используется | `.hero` (главная), `.page-intro` (внутренние страницы) |
| Варианты | `hero-road-640`, `hero-road-960`, `hero-road-1280` в AVIF и WebP |

Исходный PNG весил 2,7 МБ и загружался на каждой странице. Телефон
теперь получает вариант шириной 640 px (около 32 КБ), десктоп — 1280 px.
Поверх фотографии лежит плотный тёмно-зелёный градиент, поэтому сжатие
с качеством 62 визуально не заметно.

## Фотография реки Оки в футере

| | |
|---|---|
| Исходник | `assets/source/oka-original.png`, 2172×724, 2,18 МБ |
| **Автор** | **владелец сайта** |
| **Права** | **собственная фотография автора; публикация разрешена автором** |
| Где используется | блок `.footer-photo` над футером на всех страницах |
| Варианты | `oka-800` (18–28 КБ) и `oka-1600` (58–94 КБ) в AVIF, WebP и JPEG |

Снимок не из внешнего банка изображений: его передал владелец сайта
и подтвердил своё авторство и разрешение на публикацию. Поэтому ссылка
на страницу первоисточника и название публичной лицензии здесь
неприменимы — правами распоряжается сам автор.

Кадр: широкая излучина реки на закате, заливные луга и лес по берегам.
Соотношение сторон исходника 3:1, для полосы в футере кадрируется
до 8:3. На телефоне берётся более крупный фрагмент ближе к центру,
чтобы изгиб русла оставался в кадре; изображение не растягивается —
используется `object-fit: cover`. Подпись читается благодаря
тёмно-зелёному градиенту снизу.

### Если понадобится заменить фотографию

Для снимка из внешнего источника лицензия обязательна:

```bash
npm run photo:oka -- путь/к/фотографии.jpg \
  --source "https://commons.wikimedia.org/wiki/File:ИМЯ_ФАЙЛА" \
  --license "CC0 1.0" \
  --author "Имя автора"
```

Скрипт откажется работать, если лицензия не Public Domain и не CC0,
если фотография не широкоформатная (нужно соотношение не меньше 1,5)
или если она уже́ 1200 px.

Для собственного снимка владельца лицензия не проверяется, но это
отмечается в документации:

```bash
npm run photo:oka -- путь/к/фотографии.png --owner-supplied \
  --author "Имя автора"
```

## Схема проезда на странице «Контакты»

| | |
|---|---|
| Исходник | `assets/source/contact-map.png`, 1983×793, 2,34 МБ |
| Происхождение | передана владельцем сайта готовой |
| Где используется | блок «Как нас найти» на странице `/contacts` |
| Варианты | `contact-map-900`, `contact-map-1400`, `contact-map-1980` в AVIF и WebP, исходный PNG сохранён |

География, подписи и номера участков на схеме не изменялись.

Подложка схемы — спутниковый снимок из Яндекс.Карт, на изображении
видны отметки сервиса. Условия использования картографических сервисов
обычно требуют сохранять отметку правообладателя и ограничивают
коммерческое применение. Отметки на схеме сохранены; вопрос о праве
на публикацию решает владелец сайта.
