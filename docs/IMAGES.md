# Изображения проекта

Все изображения хранятся внутри проекта. Внешние ссылки на картинки
не используются: сайт должен открываться, даже если сторонний сервис
недоступен.

- Исходники: `assets/source/`
- Готовые варианты: `assets/img/` (собираются командой `npm run images`)

Исходный PNG весил 2,7 МБ и загружался на каждой странице. Телефон
теперь получает вариант шириной 640 px (около 32 КБ), десктоп — 1280 px.
Поверх фотографии лежит плотный тёмно-зелёный градиент, поэтому сжатие
с качеством 62 визуально не заметно.

Логотип показывается размером 40–58 px, поэтому варианта 128 px хватает
даже для экранов с двойной плотностью пикселей.

## Фотография реки Оки в футере — не установлена

Блок для широкоформатной фотографии реки Оки готов: стили
(`.footer-photo` в `assets/site.css`), кадрирование под телефон,
тёмно-зелёный градиент для читаемости подписи и ленивая загрузка.
Самой фотографии в проекте нет.

**Причина:** в среде, где выполнялась работа, закрыт доступ ко всем
источникам изображений (Викисклад, Flickr, Pexels, Pixabay,
Openverse, Библиотека Конгресса и другие). Подобрать файл и, главное,
открыть его страницу источника, чтобы **убедиться** в лицензии, было
невозможно. Ставить непроверенное изображение нельзя, поэтому блок
оставлен неподключённым.

### Как добавить фотографию

1. Найдите широкоформатный снимок Оки на изгибе русла. Проверенные
   источники, где лицензия указана на странице файла:
   - [Викисклад, категория «Oka River»](https://commons.wikimedia.org/wiki/Category:Oka_River)
   - [Викисклад, поиск по лицензии CC0](https://commons.wikimedia.org/wiki/Category:CC-Zero)
2. Откройте страницу файла и убедитесь, что там указано
   **Public Domain** или **CC0**. Лицензии CC BY, CC BY-SA и любые
   «только для некоммерческого использования» не подходят.
3. Скачайте файл и выполните из корня проекта:

```bash
npm run photo:oka -- путь/к/фотографии.jpg \
  --source "https://commons.wikimedia.org/wiki/File:ИМЯ_ФАЙЛА" \
  --license "CC0 1.0" \
  --author "Имя автора"
```

Скрипт сам:

- откажется работать, если лицензия не Public Domain и не CC0;
- откажется работать, если фотография не широкоформатная
  (нужно соотношение сторон не меньше 1,5) или уже́ 1200 px;
- соберёт варианты 800 px и 1600 px в AVIF, WebP и JPEG;
- вставит блок с фотографией в футер всех страниц;
- допишет источник, автора и лицензию в этот файл.

Требования к самой фотографии: ширина не меньше 1600 px, изгиб или
поворот русла в кадре, спокойный природный сюжет без людей и техники
крупным планом.
