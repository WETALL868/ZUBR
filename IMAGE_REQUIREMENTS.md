# Требования к изображениям

Все изображения в `public/images/` на данный момент — это **временные SVG-иллюстрации**,
сгенерированные скриптом `scripts/generate-images.mjs`. Они выполнены в фирменной палитре
(тёплый фон, графитовый `#174C48`, бронзовый акцент `#B98242`) и нужны только для того, чтобы
сайт выглядел цельно и не имел «битых» изображений при первом запуске.

**Перед публикацией сайта каждую иллюстрацию нужно заменить на реальную фотографию.**
В названиях файлов сохранена смысловая структура — при замене используйте те же имена файлов
и то же соотношение сторон, чтобы вёрстка не съехала (или обновите пути в файлах `src/data/*.ts`).

Требования к реальным фото:
- коммерческая лицензия или собственные фотографии компании;
- согласованная цветокоррекция (нейтральные тона, дневной/мягкий вечерний свет);
- без чужих логотипов, водяных знаков и посторонних людей;
- высокое разрешение (см. рекомендации ниже), формат JPG/WebP, оптимизированные для веба.

## Открытая графика (Open Graph / favicon)

Изображение для соцсетей генерируется динамически в `src/app/opengraph-image.tsx`, а иконка сайта —
в `src/app/icon.tsx`. Если у компании появится готовый логотип, замените эти файлы на статичные
`opengraph-image.png` (1200×630) и `icon.png`/`favicon.ico` — Next.js подхватит их автоматически.

## Как пересоздать плейсхолдеры

```bash
node scripts/generate-images.mjs
```

Скрипт перезапишет все SVG-иллюстрации в `public/images/`. Используйте его только для черновой
вёрстки — финальный сайт должен содержать реальные фотографии.
