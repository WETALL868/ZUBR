## Установка

Команды из корня сайта (папка с `src/` и `resources/`); пакет распакован в `<пакет>`.

1. Резервная копия: `mkdir -p otkat-raspisanie && cp -p resources/app.js resources/build.json src/Shop.php src/MailTpl.php otkat-raspisanie/`
2. Суммы основы: `sha256sum -c <пакет>/check/osnova-20261101.sha256` (8 строк OK).
3. Проверка без записи, полный режим: `python3 <пакет>/ubrat_raspisanie.py .`
   - ожидается (так печатает скрипт на основе 01.11):
     `./resources/app.js: 3aeb36147e0eaba8 -> f9d3ca24da5b681b`, `./src/Shop.php: 40602e80de70e11d -> d5f080b3153b63f6`,
     `./src/MailTpl.php: 2c571f1e82711c1c -> a72f7e535fab7dda`, `./resources/build.json: 5a3adc21ac8ab2c4 -> 78ea153a2928d60b`,
     затем `app.js: основа совпадает с ожидаемой (рабочий сайт 30.10.2026)` и «Проверка без записи»;
   - если Shop.php или MailTpl.php на сервере успели измениться и скрипт остановился на них («фрагмент найден 0
     раз(а)»), ставить только app.js и build.json: `python3 <пакет>/ubrat_raspisanie.py . --tolko-app` (проверка),
     затем с `--zapis`; эти два файла прислать мне (без config.php и секретов), часть с ними пересоберу на них.
4. Запись: `python3 <пакет>/ubrat_raspisanie.py . --zapis` (или `--tolko-app --zapis`, см. шаг 3).
5. Проверка: `sha256sum -c <пакет>/check/posle.sha256` (8 строк OK; после `--tolko-app`: `check/posle-tolko-app.sha256`);
   `php -l src/Shop.php && php -l src/MailTpl.php`; повторный запуск шага 3 говорит «правка уже есть».
6. Кэш чистить не нужно: сборка app.js с контактами (`storage/cache/app-*.js`) создается заново по новой метке, у
   браузеров новый адрес `/app.js?v=…`. Если у PHP opcache без проверки времени файлов
   (`opcache.validate_timestamps=0`), перезапустить PHP-FPM.

## Откат

1. Из резервной копии: `python3 <пакет>/ubrat_raspisanie.py . --otkat otkat-raspisanie`
   (после `--tolko-app`: `python3 <пакет>/ubrat_raspisanie.py . --tolko-app --otkat otkat-raspisanie`, вернет только
   app.js и build.json), или вручную `cp -p` из `otkat-raspisanie/`.
2. Без копии: `python3 <пакет>/ubrat_raspisanie.py . --obratno --zapis` (с `--tolko-app`, если ставились только app.js
   и build.json). На основе 01.11 все 4 файла возвращаются байт в байт (метка 3aeb36147e снова; проверено на копии).
3. При opcache без проверки времени файлов перезапустить PHP-FPM.
