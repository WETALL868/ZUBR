  4. Корзина, уведомление при смене цены в открытой вкладке: «Началась скидка по расписанию (…)» и «Скидка по расписанию закончилась…».

строки нужны покупателю по смыслу (сумма скидки, предупреждение о смене цены, отказ промокода), поэтому из них убраны
