Готовые файлы документов каталога.

Состав каталога описан в docs/documents-catalog.json (поле file),
имена продублированы в атрибуте data-file у карточек
в documents/index.html.

Как добавить документ:
  1. Положите скан в assets/source/documents/
  2. Опишите его в docs/documents-catalog.json
  3. npm run documents:prepare   — сожмёт скан для медленного интернета
  4. npm run documents          — пересоберёт страницу каталога

Пока файла нет, карточка показывает «Файл готовится к публикации»
без ссылки — чтобы на сайте не было переходов, ведущих на ошибку 404.
