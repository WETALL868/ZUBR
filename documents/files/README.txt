Сюда кладутся файлы документов каталога.

Имена файлов перечислены в docs/documents-catalog.json (поле file)
и продублированы в атрибуте data-file у карточек в documents/index.html.

Как только файл появится в этой папке, у соответствующей карточки
автоматически появится кнопка «Скачать» — для этого выполните
`npm run documents` (локально) и загрузите обновлённый documents/index.html.
