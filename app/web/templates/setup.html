Шаг 1 и 2. Данные для подключения
Сначала получите пароль приложения Яндекса — обычный пароль от почты не подойдёт.
  1. Откройте id.yandex.ru → Безопасность → Пароли приложений.
  2. Выберите тип «Почта», придумайте название, нажмите «Создать».
  3. Скопируйте пароль из 16 символов и вставьте его в поле ниже.
Ещё нужно один раз включить IMAP: в Яндекс.Почте Настройки → Почтовые программы → разрешить доступ по IMAP.
